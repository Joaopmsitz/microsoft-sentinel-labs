# 🛡️ Microsoft Sentinel Labs

Hands-on Microsoft Sentinel laboratory environment created for **SC-200 preparation** and **Security Operations practice**.

This repository documents practical activities involving Microsoft Sentinel, Microsoft Defender XDR, Azure monitoring, endpoint telemetry, KQL, security event investigation, threat hunting, and SOC operations.

> **End of the current lab. Not the end of the journey.**
